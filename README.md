# 📈 Stock Portfolio Tracker

A simple and interactive **Python Desktop GUI Application** to manage personal stock investments, calculate total portfolio value, and export breakdown summaries in CSV and Text formats.

Built as part of an Internship Technical Task.

---

## ✨ Key Features

- **Interactive GUI**: Built using `tkinter` with dropdown stock selection and quantity inputs.
- **Real-Time Total Calculation**: Automatically updates itemized totals and overall portfolio value.
- **File Exporting**: Save structured summaries as `portfolio_summary.csv` and `portfolio_summary.txt`.
- **Input Validation**: Handled edge cases for invalid quantity entries and empty submissions.

---

## 🛠️ Tech Stack & Requirements

- **Language**: Python 3.8+
- **GUI Framework**: Tkinter (Built-in)
- **Data Export**: `csv`, `datetime` (Built-in)
